# 🏥 NHS Hospital AI Agent — Frontend

> A modern frontend interface for an AI-powered hospital assistance platform.

## 📌 Overview

The **NHS Hospital AI Agent — Frontend** is the user-facing web application developed as part of an AI-powered hospital assistance project.

My contribution to this project focuses on the **frontend development**, including the user interface, application layout, responsive design, and integration of the frontend with the AI functionality provided by the project.

The application was developed using **React, TypeScript, Vite, and Google AI Studio/Gemini**.

## 🚀 Running the Frontend

### Prerequisites

* Node.js
* npm
* Required project environment variables

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/NHS-Hospital-AI-Agent.git
```

Navigate to the project:

```bash
cd NHS-Hospital-AI-Agent
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables using `.env.example`.

Then start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 🔐 Security

Sensitive credentials should never be committed to the repository.

Environment variables should be stored locally and excluded from version control.

**Never expose API keys directly in frontend source code or commit them to GitHub.**
